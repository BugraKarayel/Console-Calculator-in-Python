# Console Calculator in Python

🇹🇷 **Türkçe** | 🇬🇧 **English**

---

## 🇹🇷 Türkçe (Turkish)

Bu proje, Python ile geliştirilmiş kapsamlı bir konsol hesap makinesidir. Kullanıcıdan alınan matematiksel işlemleri terminal üzerinden hızlı ve güvenli bir şekilde hesaplar.

### Özellikler
- Toplama, Çıkarma, Çarpma, Bölme gibi temel matematiksel işlemler.
- Hatalı girişlere karşı koruma (Örn: harf girilmesi veya sıfıra bölme hataları).
- Modüler tasarım ve yardımcı fonksiyonlar ile temiz kod yapısı.

### Nasıl Çalıştırılır?
Terminalinizi (veya komut satırınızı) açın ve projenin bulunduğu dizinde şu komutu çalıştırın:
```bash
python Console_Calculator.py
```
*(Eğer Windows'ta `python` komutu çalışmazsa, `py Console_Calculator.py` olarak deneyebilirsiniz.)*

## 🇬🇧 English

This project is a comprehensive console-based calculator developed in Python. It calculates mathematical operations received from the user quickly and safely via the terminal.

### Features
- Basic mathematical operations such as Addition, Subtraction, Multiplication, and Division.
- Protection against invalid inputs (e.g., entering letters or divide-by-zero errors).
- Clean code structure with a modular design and helper functions.

### How to Run?
Open your terminal (or command prompt) and run the following command in the project directory:
```bash
python Console_Calculator.py
```
*(If the `python` command doesn't work on Windows, you can try `py Console_Calculator.py` instead.)*
